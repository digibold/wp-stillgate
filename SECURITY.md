# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

Stillgate is at an early `0.x` stage. Until a `1.0` release, only the
latest `0.1.x` release is supported with security fixes.

## Reporting a vulnerability

Please do not open a public GitHub issue for a security vulnerability.

If this repository has [private vulnerability reporting][private-reporting]
enabled, using the "Report a vulnerability" button under the Security tab is
the preferred way to report an issue: it opens a private conversation with
the maintainers only.

Otherwise, please report it by email to **security@createit.lv**.

When reporting, please include:

- The plugin version and the WordPress and PHP versions you tested against.
- A description of the vulnerability and its impact.
- Steps to reproduce it, including any specific configuration (freeze state,
  user role/capabilities, multisite or not) needed to trigger it.
- Whether you are aware of it being exploited in the wild.

Please do not include real user data, credentials, or production URLs in
your report.

### What to expect

- We will acknowledge your report and work with you to understand and
  confirm the issue.
- We will let you know once a fix is available and agree with you on a
  reasonable disclosure timeline before any public details are published.
- We do not currently offer a paid bug bounty.

[private-reporting]: https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability
